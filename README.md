# GGPS Sawarcup - School Management System (Neon Postgres)
Frontend (`index.html`, `style.css`, `app.js`, `config.js`) -> GitHub Pages / Vercel. Data -> Neon Postgres.

## Features Updated
- Local timezone date fix (always loads today's real attendance records).
- High-contrast dark theme with Bootstrap Icons for clear readability on mobile and desktop.
- Fast parallel Neon DB loading and saving with instant button loading spinners.
- Working Daily & Monthly CSV Attendance Export.

## Local Setup
1. `npm install`
2. Ensure `.env` has your `DATABASE_URL`.
3. Open `index.html` using Live Server or deploy directly to GitHub Pages / Vercel.
